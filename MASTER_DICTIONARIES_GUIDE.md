# Master Dictionaries User Guide

## Overview

The Master Dictionaries feature allows you to maintain reusable dictionaries for professional document generation in the Magra Automation system. These dictionaries include:

- **Purpose Library**: Maps procurement categories to professional procurement purposes
- **Item Hindi Mappings**: Maps English item names to Hindi phonetic transliterations
- **Vendor Hindi Mappings**: Maps English vendor names and locations to Hindi

Once configured, these mappings are automatically applied to all relevant tender documents, ensuring consistent professional formatting across all tenders.

---

## Accessing Master Dictionaries

1. Navigate to **Settings** from the main navigation menu
2. Scroll down to the **Master Dictionaries** section
3. The interface displays three tabs:
   - **Purpose Library**
   - **Item Hindi Mappings**
   - **Vendor Hindi Mappings**

## Purpose Library

### What is the Purpose Library?

The Purpose Library allows you to map procurement categories (like "fire_fighting", "water_supply", "chemicals") to professional procurement purposes (like "अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री").

When creating tender documents, the system automatically uses these professional purposes instead of raw item names, resulting in more formal government-style documentation.

### Adding a New Mapping

1. Click the **Add Mapping** button in the Purpose Library tab
2. Fill in the following fields:

   **Category** (Required):
   - Use snake_case format (e.g., `fire_fighting`, `water_supply`, `electrical_materials`)
   - This should match the category you'll use when adding items to tenders

   **Professional Purpose** (Required):
   - Enter the formal procurement purpose in Hindi or English
   - Example (Hindi): `अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री`
   - Example (English): `Materials required for fire fighting and water supply work`

   **Language** (Required):
   - Select either **Hindi** or **English**
   - This determines which language version is used in documents

3. Click **Add Mapping** to save

![Add Purpose Mapping Dialog](images/add-purpose-mapping.png)

### Editing an Existing Mapping

1. Find the mapping in the list
2. Click the **Edit** button
3. Modify any fields as needed
4. Click **Save Mapping** to update

### Deleting a Mapping

1. Find the mapping in the list
2. Click the **Delete** button
3. Confirm deletion in the dialog

**Note**: Deleting a mapping will cause the system to use a temporary purpose ("संबंधित कार्य हेतु आवश्यक सामग्री") for items in that category.

### Viewing Mapping Details

Each mapping displays:
- **Category**: The procurement category
- **Purpose**: The professional procurement purpose
- **Language**: Hindi or English
- **Usage Count**: How many times this mapping has been used

## Item Hindi Mappings

### What are Item Hindi Mappings?

Item Hindi Mappings allow you to store Hindi phonetic transliterations for common item names. Once saved, these mappings are automatically applied to tender documents when generating documents in Hindi.

### Adding a New Mapping

1. Click the **Add Mapping** button in the Item Hindi Mappings tab
2. Fill in the following fields:

   **English Name** (Required):
   - Enter the exact English item name as it appears in tenders
   - Example: `Fire Hose`, `LED Street Light`, `Cement`

   **Hindi Name** (Required):
   - Enter the Hindi phonetic transliteration
   - Example: `अग्निशमन होस`, `एलईडी स्ट्रीट लाइट`, `सीमेंट`

3. Click **Add Mapping** to save

![Add Item Hindi Mapping Dialog](images/add-item-hindi-mapping.png)

### Editing an Existing Mapping

1. Find the mapping in the list
2. Click the **Edit** button
3. Modify the English or Hindi name as needed
4. Click **Save Mapping** to update

### Deleting a Mapping

1. Find the mapping in the list
2. Click the **Delete** button
3. Confirm deletion in the dialog

**Note**: Deleting a mapping will cause the system to display the original English name in documents.

### Viewing Mapping Details

Each mapping displays:
- **English Name**: The original English item name
- **Hindi Name**: The Hindi phonetic transliteration
- **Usage Count**: How many times this mapping has been used
- **Auto-generated**: Whether this was auto-generated by AI or manually added

## Vendor Hindi Mappings

### What are Vendor Hindi Mappings?

Vendor Hindi Mappings allow you to store Hindi phonetic transliterations for vendor names and locations. These are automatically applied to Supply Aadesh documents when generating documents in Hindi.

### Adding a New Mapping

1. Click the **Add Mapping** button in the Vendor Hindi Mappings tab
2. Fill in the following fields:

   **English Name** (Required):
   - Enter the exact English vendor name or location
   - Examples: `M/s ABC Suppliers`, `Indore`, `Bhopal`

   **Hindi Name** (Required):
   - Enter the Hindi phonetic transliteration
   - Examples: `एम/एस एबीसी सप्लायर्स`, `इंदौर`, `भोपाल`

3. Click **Add Mapping** to save

## Bulk Import/Export

### Exporting Mappings

You can export all mappings from any dictionary to a JSON file for backup or sharing.

1. Click the **Export** button in the dictionary tab
2. Review the export details:
   - Dictionary type
   - Number of mappings
   - Format (JSON)
3. Click **Export** to download the JSON file

**Export File Format**:
```json
[
  {
    "id": "mapping_id",
    "category": "fire_fighting",
    "professionalPurpose": "अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री",
    "language": "hindi",
    "usageCount": 5,
    "isAutoGenerated": false,
    "createdAt": "2026-05-30T...",
    "updatedAt": "2026-05-30T..."
  }
]
```

### Importing Mappings

You can import mappings from a JSON file to quickly populate dictionaries.

1. Click the **Import** button in the dictionary tab
2. Select a JSON file containing mappings
3. Review the import details
4. Click **Import** to add the mappings

**Import File Format**:
```json
[
  {
    "category": "fire_fighting",
    "professionalPurpose": "अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री",
    "language": "hindi"
  },
  {
    "category": "water_supply",
    "professionalPurpose": "जल आपूर्ति कार्य हेतु आवश्यक सामग्री",
    "language": "hindi"
  }
]
```

**Important Notes**:
- Importing will add new mappings but will not overwrite existing ones
- Each mapping is identified by its unique ID
- If a mapping with the same ID exists, it will be skipped
- Import errors are displayed in a dialog for review

## Workflow Examples

### Example 1: Setting Up a New Department

**Scenario**: You're setting up the system for a new municipal council that frequently procures fire fighting equipment.

**Steps**:

1. **Add Purpose Mapping**:
   - Category: `fire_fighting`
   - Professional Purpose: `अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री`
   - Language: Hindi

2. **Add Item Hindi Mappings**:
   - English: `Fire Hose`, Hindi: `अग्निशमन होस`
   - English: `Fire Extinguisher`, Hindi: `अग्निशमन एक्सटिंग्विशर`
   - English: `Fire Hydrant`, Hindi: `अग्निशमन हाइड्रेंट`

3. **Add Vendor Hindi Mappings**:
   - English: `M/s Safety Equipment`, Hindi: `एम/एस सेफ्टी इक्विपमेंट`
   - English: `Indore`, Hindi: `इंदौर`

**Result**: All future fire-fighting tenders will automatically use professional purposes and Hindi names.

### Example 2: Creating a Tender with Master Dictionaries

**Scenario**: You're creating a tender for fire fighting equipment.

**Steps**:

1. Navigate to **Tenders** → **New Tender**
2. Fill in tender details (title, department, language)
3. Add items with category `fire_fighting`:
   - Product Name: `Fire Hose`
   - Category: `fire_fighting`
   - Quantity: 100
   - Rate: 500

4. The system automatically:
   - Uses the professional purpose from the Purpose Library
   - Shows Hindi name for "Fire Hose" in the item table
   - Applies Hindi transliteration to vendor names in documents

5. Generate documents:
   - Vigyapti uses: "अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री"
   - Supply Aadesh subject uses the professional purpose
   - Item table shows Hindi names when language is Hindi

### Example 3: Bulk Import for Multiple Departments

**Scenario**: You have mappings for multiple departments and want to import them all at once.

**Steps**:

1. Prepare a JSON file with all mappings:
```json
[
  {
    "category": "fire_fighting",
    "professionalPurpose": "अग्निशमन एवं जल आपूर्ति कार्य हेतु आवश्यक सामग्री",
    "language": "hindi"
  },
  {
    "category": "water_supply",
    "professionalPurpose": "जल आपूर्ति कार्य हेतु आवश्यक सामग्री",
    "language": "hindi"
  },
  {
    "category": "electrical",
    "professionalPurpose": "विद्युत कार्य हेतु आवश्यक सामग्री",
    "language": "hindi"
  }
]
```

2. Navigate to **Settings** → **Master Dictionaries**
3. Click **Import** in the Purpose Library tab
4. Select the JSON file
5. Click **Import**

**Result**: All mappings are added to the Purpose Library.

## Best Practices

### 1. Use Consistent Category Names

- Use snake_case format: `fire_fighting`, not `fire-fighting` or `FireFighting`
- Be specific: `fire_hoses` instead of just `fire`
- Document your categories for team consistency

### 2. Add Hindi Mappings for Common Items

- Add mappings for items you use frequently
- This saves time on future tenders
- AI will suggest transliterations, but review and save them

### 3. Use Professional Purpose Language Matching

- If your department primarily uses Hindi, add Hindi purposes
- If your department uses English, add English purposes
- This ensures consistency in document language

### 4. Regularly Review Usage Counts

- Check which mappings are used most frequently
- Remove rarely-used mappings to keep the library clean
- Add new mappings based on common procurement categories

### 5. Backup Your Mappings

- Export mappings regularly for backup
- Store JSON files in a safe location
- Import backups if you need to restore mappings

## Troubleshooting

### Issue: Professional Purpose Not Showing in Documents

**Possible Causes**:
1. No mapping exists for the item's category
2. Mapping exists but language doesn't match document language
3. Category name in item doesn't match category in mapping

**Solutions**:
1. Add a mapping for the category
2. Ensure language matches (Hindi/Hindi or English/English)
3. Check category names match exactly (case-sensitive)

### Issue: Hindi Names Not Showing in Documents

**Possible Causes**:
1. No mapping exists for the item/vendor name
2. Document language is set to English
3. English name in item doesn't match mapping

**Solutions**:
1. Add a Hindi mapping for the name
2. Switch document language to Hindi
3. Check English names match exactly

### Issue: Import File Format Error

**Possible Causes**:
1. File is not valid JSON
2. Mapping fields don't match expected format
3. File contains invalid characters

**Solutions**:
1. Validate JSON using a JSON validator
2. Check file format matches export format
3. Re-save file as UTF-8 encoded JSON

### Issue: Export File Empty

**Possible Causes**:
1. No mappings exist in the dictionary
2. All mappings were deleted

**Solutions**:
1. Add mappings before exporting
2. Review mappings in the interface
